OTIS INSPIRATIONAL RADIO — MUSIC LIBRARY DEPLOYMENT

This ZIP contains 11 original MP3 recordings, playlist.json, index.html, widget.html and studio artwork.

TO PUBLISH:
1. Extract the ZIP. Confirm index.html, widget.html, playlist.json, assets/ and music/ are at the ROOT of the extracted folder.
2. Update the EXISTING Vercel project using a Git repository connected to that project (recommended). Importing a fresh ZIP into Vercel Drop may create a new project/URL instead of updating the existing one.
3. To use GitHub: create a private repository, upload the extracted contents (GitHub browser uploads have file and batch limitations), connect repository to the EXISTING Vercel project under Settings > Git, and deploy. Git CLI is more reliable for a large music library.
4. Test https://otis-inspirational-radio.vercel.app/playlist.json and one track at /music/otis-track-01.mp3 after deploying.
5. Embed <iframe src="https://otis-inspirational-radio.vercel.app/widget.html" title="OTIS Radio" width="100%" height="120" style="border:0;border-radius:16px" allow="autoplay"></iframe> on each school website you control.

NOTES:
- Publicly deployed MP3s are downloadable by anyone who has their URLs.
- This is NOT a 24/7 live radio stream; songs advance in the browser while the page remains open.
- Vercel Hobby plan is subject to personal/non-commercial usage rules and bandwidth limits; 11 tracks total roughly 70 MB, so repeated listening may exceed free limits.
- Browser autoplay requires user interaction.
- Verify you have rights to publish/broadcast all AI-assisted music.
- The MP4 birthday video was not included because the radio is audio-only.
